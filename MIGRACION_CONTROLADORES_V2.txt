FUTUROS CONTROLADORES

Para añadir nuevos recursos (ej: EquipoController):

1. Crear controlador extendiendo BaseController:

@RestController
@RequestMapping("/api/v1/equipos")
public class EquipoControlador extends BaseController<Equipo, EquipoDTO, Long> {
    
    @Autowired
    private EquipoService equipoService;
    
    @Autowired
    private EquipoMapper equipoMapper;
    
    @Override
    protected BaseService<Equipo, Long> getService() {
        return new BaseService<>() {
            // Implementar métodos del servicio
        };
    }
    
    @Override
    protected EquipoDTO toDto(Equipo entity) {
        return equipoMapper.toDto(entity);
    }
    
    @Override
    protected Equipo toEntity(EquipoDTO dto) {
        return equipoMapper.toEntity(dto);
    }
    
    // Solo añadir endpoints específicos de Equipo
    @GetMapping("/usuario/{usuarioId}")
    public ResponseEntity<List<EquipoDTO>> getByUsuario(@PathVariable Long usuarioId) {
        // ...
    }
}

2. Ya tienes CRUD completo heredado automáticamente


=====================================================================
TROUBLESHOOTING
=====================================================================

PROBLEMA: "No se compila BaseController"
SOLUCIÓN:
   - Verificar que esté en package: com.gestion.jugadores.controlador.base
   - mvn clean compile

PROBLEMA: "Métodos de EventoJugadorService no existen"
SOLUCIÓN:
   - Ya añadidos en EventoJugadorService.java
   - Ya implementados en EventoJugadorServiceImpl.java
   - Recompilar: mvn clean compile

PROBLEMA: "Swagger muestra controladores duplicados"
SOLUCIÓN:
   - Desactivar controladores antiguos comentando @RestController
   - O cambiar ruta de V2 a /api/v2/

PROBLEMA: "Frontend no encuentra endpoints"
SOLUCIÓN:
   - Verificar que rutas sean idénticas a controladores antiguos
   - Revisar consola del navegador (F12) para ver URLs llamadas
   - Verificar CORS en configuración de seguridad

PROBLEMA: "Autenticación falla en nuevos endpoints"
SOLUCIÓN:
   - Verificar que MySecurityConfig permita las rutas
   - Asegurar que JWT se envía en header Authorization
   - Verificar que endpoints requeridos estén en .permitAll()
